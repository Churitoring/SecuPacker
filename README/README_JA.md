## 1. 使い方

基本的なパックの流れは以下の通りです。

**ステップ 1 — プラグインのインストール**

`Churitoring_SecuPacker.js`をプロジェクトの`js/plugins/`フォルダに入れ、RPG Makerのプラグイン管理画面で有効化します。パラメーターはこの段階でご希望の設定にしておいてください。

**ステップ 2 — デプロイメントフォルダの作成**

RPG Makerで**ファイル > デプロイメント**を開き、**Windows**向けにデプロイします。

**ステップ 3 — パックの実行**

デプロイされたフォルダ内のゲーム`.exe`を実行します。パックの進行画面が自動的に表示されます。この間はウィンドウを閉じないでください。途中で強制終了しても次回起動時に自動復旧する可能性が高いですが、そのまま待つのが最善です。

**ステップ 4 — 配布**

パックが完了すると、ゲームが自動的に再起動します。この配布フォルダをそのままプレイヤーに渡すことができます。

注意：`Player Auto Update`が`true`に設定されている場合、確認ダイアログが表示された後、再起動せずに終了します。この時点でゲームを再起動しないでください。再起動すると旧バージョンへの更新が試みられます。代わりに、パックされたファイルをGitHubリリースにアップロードしてください。

- RPG Maker MV 1.6.0以上、またはRPG Maker MZ 1.0.0以上
- NW.js 0.28.1以上（推奨：0.44.3以上）

## 3. パラメーター解説

### 3-1. パックの一般設定

**Packer Auto Update**

パック開始前にGitHubから最新バージョンを取得し、`js/plugins/Churitoring_SecuPacker.js`を上書きします。このファイルを直接変更している場合は、必ず`false`に設定してください。そうしないとパックのたびに変更が元に戻されます。変更なしでそのまま使用する場合は`true`のままにしてください。

**Game Binary Name**

パックの出力ファイル名です。デフォルトは`game.bin`ですが、ここで変更できます。ファイル名のみ入力可能で、パスは含められません。予測されにくい名前に変更することをお勧めします。拡張子も変更できます。

**Track Runtime Writes**

テストプレイ中に他のプラグインがファイルを作成または変更すると、そのファイルパスが`data/SecuPacker_RuntimeWrites.txt`に記録されます。パック時にはそのリストのファイルはパックに含めずディスクにそのまま残されます。

設定ファイルなどを自動生成するプラグインを使用している場合は、このオプションを有効にしてください。特別な理由がなければデフォルト値の`true`を維持することをお勧めします。

注意：このオプションで追跡されたファイルはプレイヤー自動更新とSecuPackerの保護対象から除外されます。

**Strip Read-Only Attributes**

パックの最終クリーンアップ段階で元のリソースファイルが削除されますが、読み取り専用(R)属性が設定されていると削除に失敗します。Gitでプロジェクトを管理している場合や、ファイルに読み取り専用属性を自動的に付加するツールを使用している場合は、`true`に設定することで削除前に`attrib -R`を実行して問題を防ぎます。特別な理由がなければデフォルト値の`true`を維持することをお勧めします。

### 3-2. ファイルパック設定

**File Split**

すべてのリソースを1つのファイルにパックする代わりに、複数のパックファイルに分散させることができます。DLCリソースをベースゲームから分離したり、大規模プロジェクトを複数のファイルに分割したりする際に便利です。`false`に設定すると以下のFile Split Listの設定もすべて無視されます。

**File Split List**

どのファイル/フォルダをどのパックファイルに割り当てるかのルールを定義します。各エントリには2つの設定があります。

- **Split Bin File**: このグループのファイル名です。Game Binary Nameに設定したメインパックファイル名とは異なる名前にする必要があります。例：`dlc.bin`、`bgm.bin`
- **Split Path Patterns**: このファイルに含めるパスのリストです。`audio/bgm`のようにフォルダを指定するとその中のすべてのファイルが再帰的に含まれます。`audio/se/boss.ogg`のように単一ファイルを指定することもできます。

**Packed File Exclusions**

パックに含めずディスクに残すファイルまたはフォルダを指定します。パスはプロジェクトルートからの相対パスで、区切り文字はスラッシュ(`/`)を使用します。例：`img/system/Loading.png`、`audio/bgm`

実行時にディスクから直接読み込む必要があるファイルはここに追加してください。このリストのファイルはパック対象から除外され削除されません。

注意：このリストのファイルはプレイヤー自動更新とSecuPackerの保護対象から除外されます。

### 3-3. セキュリティ設定

**Block Launch Args Whitelist**

起動時にURLクエリ文字列またはNW.jsの起動引数にこのリストにない値が1つでも検出された場合、ゲームは即時終了します。デフォルトは空のリストで、すべての外部引数がブロックされます。許可が必要な引数があればリストに追加してください。

この検査はパックされた配布ビルドにのみ適用され、開発中のテストプレイには適用されません。

**Early Blob Resolve**

ゲームが画像ファイルを読み込む際にパスをBlob URLに変換するタイミングを`Bitmap.load`の段階まで前倒しにするオプションです。ほとんどの場合は`true`のままで構いません。

ただし、`fs.readFile`や`XMLHttpRequest`を直接インターセプトして独自の復号処理を行うプラグインを使用している場合は、競合が発生したときに`false`に設定してください。

`false`に設定すると互換性が低下する場合があります。

**Enable Cheat Detection**

バックグラウンドでハッキングツールを定期的にスキャンします。

**Excluded Binary Hashes**

環境フィンガープリントハッシュを計算する際に除外するバイナリファイルの名前（または一部）です。

`ffmpeg`がデフォルトで含まれているのはFFmpegのライセンス(LGPL)によるものです。LGPLはユーザーがそのバイナリを自分のものに置き換えられる必要があるとしており、FFmpegをハッシュに含めると置き換え時にハッシュが変わってゲームが起動しなくなるため、ライセンス準拠のためデフォルトで除外されています。

特別な理由がなければデフォルト値のままにしてください。

例：`ffmpeg.dll`（ffmpeg.dllのみ除外）  
例：`ffmpeg`（ffmpeg.dllとffmpegsumo.dllの両方を除外）

**Hash Exe Files**

`true`に設定するとゲームの`.exe`ファイルも環境フィンガープリントハッシュに含まれます。これによりパックファイルを別の`.exe`と組み合わせて実行することができなくなります。重要な点として、アイコンの変更やマニフェストの修正など`.exe`を変更する作業はパック**前**に完了させる必要があります。パック後に`.exe`を変更するとハッシュが変わりゲームが起動しなくなります。

### 3-4. 追加設定

**Block Window Resize**

`true`に設定するとプレイヤーはゲームウィンドウのサイズを変更したり最大化したりできなくなります。最大化ボタンが消えるか機能しなくなる場合があります。

**Block F2 / F4 / F5 Key**

それぞれフレームレート表示(F2)、全画面切り替え(F4)、ゲームのリフレッシュ(F5)をブロックします。配布用ゲームでプレイヤーがこれらの機能を使用できないようにしたい場合は有効にしてください。

---

### 3-5. プレイヤー自動更新設定

**Player Auto Update**

`true`に設定するとゲーム起動時にGitHubリリースサーバーと通信し、新しいバージョンのパックファイルがあれば自動的にダウンロードして置き換えます。この機能を使用するには、以下の`Player Auto Update URL`も設定する必要があります。

`true`に設定されている場合、パック完了後にゲームは再起動せずに終了します。この時点でゲームを再起動しないでください。再起動すると旧バージョンへの更新が試みられます。代わりにパックファイルをGitHubリリースにアップロードしてください。

パックが正しく行われたかテストする必要がある場合は、`false`に設定した上でテストしてください。

**Player Auto Update URL**

更新を取得するGitHubリポジトリのURLです。`https://github.com/ユーザー名/リポジトリ名`の形式で入力してください。プライベートリポジトリはサポートされていません。

例：`https://github.com/Churitoring/SecuPacker`

**Player Auto Update Tag**

空白のままにすると、常に最新リリースから更新します。

タグを指定した場合、そのタグを持つ最新リリースから更新します。1つのリポジトリを作成してゲームごとのタグをリリースに付けることをお勧めします。こうすることでSecuPackerのPlayer Auto Update機能を複数のゲームで使用しても、単一のリポジトリで管理できます。

例：`SecuPacker`

**Disable On No Internet / Disable On Fail**

インターネットがない場合や更新サーバーに接続できない場合の動作を設定します。

インターネット未接続時のみゲームを終了させたいが更新機能は使いたくない場合は、`Player Auto Update`を`true`、`Player Auto Update URL`を空白、`Disable On No Internet`を`true`、`Disable On Fail`を`false`に設定することをお勧めします。

- `Disable On No Internet`を`true`にするとインターネット接続がない場合に警告を表示してゲームを終了します。
- `Disable On Fail`を`true`にするとサーバーには接続できたがファイルを取得できない場合もゲームを終了します。

**更新画面設定 (PAU Scene \*)**

自動更新中に表示される画面のUIを設定します。

*テキスト*

- **PAU Scene Update Text**: ダウンロード中にタイトル部分に表示するテキスト。デフォルト：`Updating...`
- **PAU Scene Complete Text**: 更新が正常に完了したときにタイトル部分に表示するテキスト。デフォルト：`Update complete!`
- **PAU Scene Failed Text**: 更新が失敗したときにタイトル部分に表示するテキスト。デフォルト：`Update failed`

*アニメーション*

- **PAU Scene Blink**: タイトルテキストに呼吸するような不透明度アニメーションを適用します。デフォルト：`true`
- **PAU Scene Blink Speed**: 点滅サイクルの速度。値が大きいほど速くなります。`0.050`で60fps時に約2秒に1サイクル。範囲：`0.001`～`1.000`、デフォルト：`0.050`

*進行率*

- **PAU Scene Show Progress**: ダウンロード中にサブテキストエリアに進行率(%)と容量(KB)を表示します。デフォルト：`true`

*背景*

- **PAU Scene BG Type**: 背景の種類を選択します。`color`（単色）/`image`（画像）/`video`（動画）。デフォルト：`color`
- **PAU Scene BG Color**: 種類が`color`の場合のCSSカラーコード。デフォルト：`#000000`
- **PAU Scene BG Image**: 種類が`image`の場合の背景画像ファイル。`img/`フォルダから選択します。
- **PAU Scene BG Video**: 種類が`video`の場合の動画ファイルパス。文字列で入力します。例：`movies/bg.webm`
- **PAU Scene BG Fit**: 画像または動画のアスペクト比が画面と合わない場合の表示方法。`cover`（トリミングして画面全体を埋める）/`contain`（レターボックス、アスペクト比維持）/`fill`（画面に合わせて引き伸ばす）。デフォルト：`cover`
- **PAU Scene Video Loop**: 背景動画をループ再生します。`false`の場合、最後のフレームで停止します。デフォルト：`true`
- **PAU Scene Video Volume**: 背景動画の音量。`0`（ミュート）～`100`。デフォルト：`100`

*背景音楽*

- **PAU Scene BG Music**: 更新画面で再生する音楽ファイル。`audio/`フォルダから選択します。動画背景と同時に使用できます。
- **PAU Scene BG Music Volume**: 背景音楽の音量。`0`（無音）～`100`。デフォルト：`80`
- **PAU Scene BG Music Loop**: 背景音楽をループ再生します。`false`の場合、1回再生して停止します。デフォルト：`true`

*タイトルテキストスタイル*

- **PAU Scene Title X Offset**: タイトルテキストの画面中央からの水平ピクセルオフセット。`0` = 中央揃え。デフォルト：`0`
- **PAU Scene Title Y Offset**: タイトルテキストの画面中央からの垂直ピクセルオフセット。負の値で上に移動。デフォルト：`-30`
- **PAU Scene Title Size**: タイトルテキストのフォントサイズ（ピクセル）。デフォルト：`36`
- **PAU Scene Title Color**: タイトルテキストの色。CSS hex形式で入力します。デフォルト：`#ffffff`
- **PAU Scene Title Outline Width**: タイトルテキストのアウトライン幅（ピクセル）。`0` = アウトラインなし。デフォルト：`0`
- **PAU Scene Title Outline Color**: タイトルテキストのアウトライン色。CSS hexまたは`rgba()`形式をサポート。デフォルト：`rgba(0,0,0,0.5)`

*サブテキストスタイル*

サブテキストは進行率やステータスメッセージが表示されるタイトル下の補助行です。

- **PAU Scene Sub X Offset**: サブテキストの画面中央からの水平ピクセルオフセット。デフォルト：`0`
- **PAU Scene Sub Y Offset**: サブテキストの画面中央からの垂直ピクセルオフセット。デフォルト：`30`
- **PAU Scene Sub Size**: サブテキストのフォントサイズ（ピクセル）。デフォルト：`18`
- **PAU Scene Sub Color**: サブテキストの色。CSS hex形式で入力します。デフォルト：`#888888`
- **PAU Scene Sub Outline Width**: サブテキストのアウトライン幅（ピクセル）。`0` = アウトラインなし。デフォルト：`0`
- **PAU Scene Sub Outline Color**: サブテキストのアウトライン色。CSS hexまたは`rgba()`形式をサポート。デフォルト：`rgba(0,0,0,0.5)`

## 4. JavaScript API

プラグインコマンドの代わりに、他のプラグインやスクリプト呼び出しから直接使用できるAPIです。

APIを直接呼び出すとSecuPackerへの依存関係が発生します。プラグインを無効にした際のサイドエフェクトを防ぐため、呼び出し前に存在確認の例外処理を行ってください。

**`SecuPacker.getVersion()`**

SecuPackerのバージョン文字列を返します。

```javascript
SecuPacker.getVersion();
```

**`SecuPacker.isPacked()`**

ゲームがパックモードで実行中であれば`true`、そうでなければ`false`を返します。開発中のテストプレイでは常に`false`を返すため、配布ビルドかどうかで動作を分岐させる際に活用できます。

```javascript
if (SecuPacker.isPacked()) {
    // 配布ビルドでのみ実行するコード
}
```

**`SecuPacker.isSplitAvailable(binName)`**

指定した名前の分割パックファイルが存在しアクセス可能であれば`true`を返します。DLCファイルがインストールされているかどうかを確認する際に使用できます。

```javascript
SecuPacker.isSplitAvailable("dlc.bin"); // true または false
```

**`SecuPacker.isPlayerAutoUpdateReady()`**

プレイヤー自動更新が有効かつURLが設定されている場合に`true`を返します。

```javascript
SecuPacker.isPlayerAutoUpdateReady(); // true または false
```

## 5. プラグインコマンド

MZで使用可能なプラグインコマンドです。

**GetVersion** — SecuPackerのバージョン文字列をゲーム変数に格納します。

**IsPacked** — ゲームがパック済みの場合は`true`、そうでない場合は`false`をゲーム変数に格納します。配布ビルドかどうかでゲーム内の動作を分岐させる際に使用します。

**IsSplitAvailable** — 指定した名前の分割パックファイルが存在しアクセス可能かどうかを確認し、結果をゲーム変数に格納します。DLCファイルの有無を確認する際に活用できます。

**IsPlayerAutoUpdateReady** — プレイヤー自動更新が有効かつURLが設定されている場合に`true`をゲーム変数に格納します。

## 6. 注意事項

- **プロジェクトファイルの保護**: デプロイメントフォルダ内に`*.rpgproject`または`*.rmmzproject`ファイルが存在する場合、開発ディレクトリとして判断しパックを中断します。必ずデプロイされたフォルダから実行してください。
- **個人情報に注意**: 完全なセキュリティは存在しません。どんなに安全なシステムでも誰かが突破できる可能性があります。ID、パスワード、APIキーなどの個人情報や機密情報はゲームファイルに含めないでください。
- **著作権に注意**: パックファイルと同じ場所にある`LICENSE.txt`を削除しないでください。削除して配布すると著作権法に抵触する可能性があります。
- **パック後の黒い画面**: パック前のテストプレイでは正常に動作していたのに、パック後にゲームを実行するとエラーメッセージとともに黒い画面で止まる場合があります。これはMVの場合は`index.html`、MZの場合は`main.js`に登録されたスクリプトにエラーがある場合に発生します。スクリプトを追加したり登録済みのスクリプトを変更したりした場合は、それが原因である可能性が高いです。
